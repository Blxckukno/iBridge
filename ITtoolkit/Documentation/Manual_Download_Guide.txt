## Instructions:
1. Download each file manually from the official website
2. Place downloaded files in the correct folder structure:
   - Freeware files go in `Freeware/[Category]/`
   - FOSS files go in `FOSS_Enterprise_Stack/[Category]/`
3. Update the Software_Versions.csv with actual downloaded versions
4. Re-run the install script to include newly downloaded applications

## Note:
Some downloads require:
- Account registration (Veeam, Oracle Java)
- License agreement acceptance
- Email verification
- Manual captcha completion

This is normal for enterprise-grade software and ensures compliance with vendor terms.
