# Antivirus & Cybersecurity System

A modular, cross-platform antivirus and cybersecurity system in Python. Features include real-time scanning, scheduled scans, quarantine, firewall/network monitoring, process monitoring, automatic updates, UI, logging, web/email protection, ransomware protection, and resource optimization.

## Project Structure
- core_engine: Main engine and utilities
- realtime_scanner: Real-time file and process monitoring
- scheduled_scans: Scheduled scan logic
- quarantine: Threat isolation and removal
- firewall: Network and firewall monitoring
- process_monitor: Suspicious process/behavior monitoring
- updates: Automatic updates
- ui: User interface/dashboard
- logging: Logging and reporting
- web_email_protection: Web and email protection
- ransomware_protection: Ransomware detection
- resource_optimization: System resource management
