# Backup Directory

This directory stores backup files of current configurations before making changes.

## Backup Files

- **Transport Rules**: `transport-rules-YYYYMMDD.csv`
- **Mailbox Permissions**: `permissions-{mailbox}-YYYYMMDD.csv`
- **Configuration Snapshots**: JSON exports of current settings

## Best Practices

- Create backups before any configuration changes
- Keep backups for at least 6 months
- Test restore procedures regularly
- Document any manual configuration changes
